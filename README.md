# 5LSM0: Neural Networks for Computer Vision - NNCV_sven

Files:
- model1.py: contains the baseline model
- train1.py: contains code to train the baseline model
- model2.py: contains the SegFormer model
- train2.py: contains code to train the SegFormer model
- lossDice.py: contains code to compute the Dice loss
- loadModel.py: contains code to prepare the model.pth file for CodaLab submission



Required packages:
- torch
- torchvision
- transformers
- wandb
- pillow
- numpy
